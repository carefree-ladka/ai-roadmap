# Dependency Injection

<TOCInline toc={toc} minHeadingLevel={2} maxHeadingLevel={2} />

:::tip[In this guide]
FastAPI's `Depends` system — the clean way to share logic (DB sessions, auth,
config) across endpoints and to swap implementations in tests.
:::

## What Is It?

Dependency injection (DI) lets a route declare *what it needs*; FastAPI
*provides* it by calling a dependency function.

## Why Does It Matter?

DI removes duplication (auth checks, DB sessions), makes endpoints declarative,
and makes testing trivial via **overrides**.

## Basic Dependency

```python
from fastapi import Depends, FastAPI

app = FastAPI()

def pagination(skip: int = 0, limit: int = 10) -> dict:
    return {"skip": skip, "limit": limit}

@app.get("/items")
def list_items(page: dict = Depends(pagination)):
    return page
```

FastAPI calls `pagination()`, injects the result, and documents `skip`/`limit`
as query params.

## Reusable Dependencies

Define once, reuse everywhere:

```python
from typing import Annotated

Pagination = Annotated[dict, Depends(pagination)]

@app.get("/users")
def list_users(page: Pagination):
    return page
```

`Annotated` + `Depends` is the modern, DRY style.

## Request-Scoped Dependencies (yield)

Use `yield` for setup/teardown per request (perfect for DB sessions):

```python
def get_db():
    db = SessionLocal()
    try:
        yield db              # provided to the endpoint
    finally:
        db.close()            # cleanup after the response

@app.get("/things")
def read_things(db=Depends(get_db)):
    return db.query_all()
```

## Database Dependency

```python
from typing import Annotated
from sqlalchemy.orm import Session

DbSession = Annotated[Session, Depends(get_db)]

@app.get("/users/{user_id}")
def get_user(user_id: int, db: DbSession):
    return db.get(User, user_id)
```

## Authentication Dependency

A dependency can enforce auth and return the current user:

```python
from fastapi import Depends, HTTPException, status

def get_current_user(token: str = Depends(oauth2_scheme)):
    user = decode_and_lookup(token)
    if user is None:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "invalid token")
    return user

@app.get("/me")
def me(user=Depends(get_current_user)):
    return user
```

See [Authentication](./07-authentication-authorization.mdx) for the full flow.

## Sub-Dependencies

Dependencies can depend on other dependencies:

```python
def get_settings():
    return settings

def get_llm_client(cfg=Depends(get_settings)):
    return OllamaClient(cfg.ollama_url)
```

## Dependency Overrides for Tests

Swap a dependency with a fake during tests — no real DB or network:

```python
from app.main import app
from app.dependencies import get_db

def fake_db():
    yield InMemoryDb()

app.dependency_overrides[get_db] = fake_db
# ... run tests with TestClient ...
app.dependency_overrides.clear()
```

## Common Mistakes

- Doing setup/teardown without `yield` (resources leak).
- Recreating expensive clients per request instead of reusing them.
- Forgetting to `clear()` overrides between test modules.

## Things to Remember

- `Annotated[..., Depends(...)]` for reusable, typed deps.
- `yield` for per-request setup/teardown.
- `dependency_overrides` make tests isolated.
