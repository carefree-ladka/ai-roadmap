## Authentication vs Authorization

- **Authentication (authn)**: verifying identity — "who are you?"
- **Authorization (authz)**: checking permissions — "are you allowed to do this?"

## Password Hashing

Store a **hash**, never the password. Use a slow, salted algorithm (bcrypt):

```python
from passlib.context import CryptContext

pwd = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(raw: str) -> str:
    return pwd.hash(raw)

def verify_password(raw: str, hashed: str) -> bool:
    return pwd.verify(raw, hashed)
```

## OAuth2 Password Flow + JWT

A **JWT** (JSON Web Token) is a signed token carrying claims (like the user id
and expiry). The server verifies the signature instead of hitting the DB for
every request.

```python
from datetime import datetime, timedelta, timezone
import jwt                                   # PyJWT
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm

SECRET_KEY = "load-this-from-env-not-here"  # e.g. settings.secret_key
ALGORITHM = "HS256"

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

def create_access_token(subject: str, minutes: int = 15) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=minutes)
    return jwt.encode({"sub": subject, "exp": expire}, SECRET_KEY, algorithm=ALGORITHM)
```

### Login endpoint

```python
@app.post("/token")
def login(form: OAuth2PasswordRequestForm = Depends()):
    user = get_user(form.username)
    if not user or not verify_password(form.password, user.hashed_password):
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "bad credentials")
    access = create_access_token(user.username, minutes=15)
    refresh = create_access_token(user.username, minutes=60 * 24 * 7)
    return {"access_token": access, "refresh_token": refresh, "token_type": "bearer"}
```

### Current-user dependency

```python
def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload["sub"]
    except jwt.PyJWTError:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "invalid token")
    user = get_user(username)
    if user is None:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "user not found")
    return user

@app.get("/me")
def me(user=Depends(get_current_user)):
    return {"username": user.username}
```

## Access vs Refresh Tokens

- **Access token**: short-lived (minutes). Sent on every request.
- **Refresh token**: long-lived (days). Used only to obtain a new access token.

Short access tokens limit the damage if one leaks; refresh tokens avoid asking
users to log in constantly.

## Role-Based Authorization

```python
from fastapi import Depends, HTTPException, status

def require_role(role: str):
    def checker(user=Depends(get_current_user)):
        if role not in user.roles:
            raise HTTPException(status.HTTP_403_FORBIDDEN, "insufficient role")
        return user
    return checker

@app.delete("/users/{user_id}")
def delete_user(user_id: int, admin=Depends(require_role("admin"))):
    ...
```

## Common Mistakes

- Storing plaintext or fast-hashed (MD5/SHA1) passwords.
- Hardcoding the JWT secret or committing it.
- Long-lived access tokens with no refresh strategy.
- Returning `200` with an error body instead of `401`/`403`.
- Trusting a token without verifying its signature and expiry.

## Things to Remember

- Hash + salt passwords (bcrypt/argon2).
- Short access tokens, longer refresh tokens.
- Secrets from environment, HTTPS everywhere.
- Enforce authz with dependencies.
