## What Is FastAPI?

A modern, high-performance Python web framework for building APIs, built on
**type hints**. Those hints drive validation, serialization, and automatic
OpenAPI docs.

## Why FastAPI?

- **Fast to write**: type hints generate validation and docs for free.
- **Fast to run**: async-first, built on ASGI.
- **Great DX**: interactive Swagger UI and ReDoc out of the box.
- **Standards-based**: OpenAPI + JSON Schema.

## ASGI and Uvicorn

- **WSGI** is the older synchronous server interface (Flask, Django historically).
- **ASGI** is the asynchronous successor — it supports async views, WebSockets, and long-lived connections.
- **Uvicorn** is a fast ASGI server that runs your FastAPI app.

## FastAPI vs Flask vs Django

| | FastAPI | Flask | Django |
| --- | --- | --- | --- |
| Style | Async, typed | Micro, sync | Batteries-included |
| Validation | Built-in (Pydantic) | Manual/extensions | Forms/DRF |
| Auto docs | Yes | No | With DRF |
| Best for | Typed async APIs / AI services | Small apps | Full web apps with ORM/admin |

## The Application Instance

```python
from fastapi import FastAPI

app = FastAPI(
    title="RAG API",
    version="0.1.0",
    description="Local-first AI API.",
)
```

## Path Operations

A "path operation" = an HTTP method + a path + a handler function:

```python
@app.get("/health")
def health():
    return {"status": "ok"}

@app.post("/echo")
def echo(message: str):
    return {"echo": message}
```

## Status Codes

```python
from fastapi import status

@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item():
    return {"created": True}
```

Common codes: `200 OK`, `201 Created`, `204 No Content`, `400 Bad Request`,
`401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `422 Unprocessable
Entity` (validation), `500 Internal Server Error`.

## Run It

```bash
uvicorn main:app --reload
```

## Swagger UI and ReDoc

FastAPI generates these automatically from your code:

- Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs) — try requests in the browser.
- ReDoc: [http://localhost:8000/redoc](http://localhost:8000/redoc) — clean reference docs.
- Raw schema: `/openapi.json`.

## Common Mistakes

- Confusing the module:variable in `uvicorn main:app` (file `main.py`, variable `app`).
- Expecting sync code to be non-blocking — a sync handler still blocks its worker.
- Forgetting `--reload` in development.
