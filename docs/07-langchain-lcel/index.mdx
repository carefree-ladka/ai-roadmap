<ProgressToggle sectionId="07-langchain-lcel" />

:::tip[In this guide]
The two dominant LLM frameworks, end to end. You'll master LangChain's building
blocks — prompts, models, output parsers, Runnables/LCEL, loaders, splitters,
retrievers, RAG chains, streaming, memory, agents, and tracing — then rebuild
RAG the LlamaIndex way and learn exactly when to reach for each (or neither).
:::

## Goal

Compose prompts, models, retrievers, and parsers into pipelines with LCEL, add
memory, agents, and observability, and build the same RAG with LlamaIndex — then
choose frameworks deliberately.

1–2 weeks.

## Where This Fits

```mermaid
flowchart LR
    Prompt --> Model[Ollama LLM]
    Retriever --> Prompt
    Model --> Parser[Output parser]
    Parser --> Result
```

LCEL pipes these components together with a clean `|` syntax.

## A Balanced View

LangChain accelerates prototyping and standardizes integrations, but adds
abstraction. For simple flows, the hand-written chain from your
[first project](../05-rag-fundamentals/03-first-project.mdx) is often clearer.
Learn both; choose deliberately.

## Interview Relevance

Expect "what is LCEL?", "when would you use an agent?", and "LangChain vs
rolling your own?" — know the tradeoffs.

## Done When

- [ ] You can build a RAG chain with LCEL + Ollama and the built-in helpers.
- [ ] You can use prompts, output parsers, and the core Runnable primitives.
- [ ] You can choose and configure the right retriever, and stream results.
- [ ] You can add conversational memory and explain when agents help or hurt.
- [ ] You can add observability with callbacks/LangSmith.
- [ ] You can build the same RAG in LlamaIndex and justify LangChain vs LlamaIndex.
