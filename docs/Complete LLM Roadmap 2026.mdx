### Attention Explained

Learn it mathematically — you should be able to write this from memory:

```text
Attention(Q, K, V) = softmax( (Q · Kᵀ) / √d_k ) · V
```

- `Q` (query), `K` (key), `V` (value) are linear projections of the input
- `Q · Kᵀ` scores how much every token should attend to every other token
- `√d_k` scaling keeps the dot products from saturating softmax
- `softmax` turns scores into attention weights that sum to 1
- multiplying by `V` produces the weighted mix of token information
