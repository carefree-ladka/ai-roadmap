# Pacing Plan

:::tip[This timeline is flexible]
Twenty weeks is a guide, not a rule. Go faster where you're comfortable, slower
where you're not. Depth and a working project beat rushing to finish.
:::

## Goal

Give your learning a shape so you keep momentum without burning out.

## The 20-Week Plan

Weeks 1–6 build the backend. Weeks 7–14 build the AI system. Weeks 15–20 make
it agentic, measurable and defensible.

are reference too. Read them when you hit the problem they solve.

## How to Use It

- **Track it** on the [Progress page](/progress) — tick sections as you finish.
- **Build as you go**: from week 11, keep improving the *same* [RAG project](./05-rag-fundamentals/03-first-project.mdx). Everything after that week is an upgrade to one codebase, not a new tutorial.
- **Don't skip fundamentals**: Python and async underpin everything after.
- **Finish each section's "Done When" checklist** before moving on. It is a better signal than the calendar.

## If You Have Less Time

| Situation | Plan |
| --- | --- |
| Already know Python | Skim weeks 1–3, start at week 4 |
| Experienced backend engineer | Skim weeks 1–6, start at week 7. This is the most common case. |
| Just want RAG, nothing else | [Prerequisites](./00-prerequisites/index.mdx), enough [async](./01-python/01-core-python/04-professional-python.mdx#async-python), then weeks 7, 9, 11, 12 |
| No GPU and no interest in serving | Skip week 8; read [NVIDIA NIM](./03-local-llms-ollama/03-nvidia-nim-endpoints.mdx) only, for the hosted-endpoint pattern |
| Interview in a month | Weeks 11–14 and 19, then [15 · AI Interview Roadmaps](./15-ai-roadmaps/index.mdx) |
| Building agents at work already | Weeks 16–18 and 19, then back-fill |

## The Minimum Viable Path

If twenty weeks is not realistic, these six weeks get you a defensible project:
**7, 9, 11, 12, 13, 19.** Local model, embeddings, a working RAG service,
retrieval you have tuned, one pattern applied deliberately, and numbers proving
it got better. That is a real portfolio piece.

## Adjusting the Plan

Life happens. If a week slips, shift the rest — the **order** matters more than
the calendar. The one non-negotiable: finish with a working, evaluated project
you can talk about.

## Done When

- [ ] You've picked a realistic cadence for your situation.
- [ ] You're tracking progress on the [Progress page](/progress).
- [ ] You're building the project continuously, not just reading.
- [ ] You can say which weeks you are skipping and why.
