# Pacing Plan

:::tip[This timeline is flexible]
Twenty-two weeks is a guide, not a rule. Go faster where you're comfortable,
slower where you're not. Depth and a working project beat rushing to finish.
:::

<TOCInline toc={toc} minHeadingLevel={2} maxHeadingLevel={2} />

## Goal

Give your learning a shape so you keep momentum without burning out.

## The 22-Week Plan

Weeks 1–6 build the backend. Weeks 7–16 build the AI system. Weeks 17–22 make
it agentic, measurable and defensible.

you reach for when the problem arrives. Read
[GPU serving engines](./13-production-genai-and-llmops/02-gpu-serving-engines.mdx) when

Deep-dive pages inside sections you've already covered — the extra FastAPI
phases, the remaining Python language guides, the LangChain complete guides —
are reference too. Read them when you hit the problem they solve.

## How to Use It

- **Track it** on the [Progress page](/progress) — tick sections as you finish.
- **Build as you go**: from week 12, keep improving the *same* [RAG project](./06-rag/03-first-project.mdx). Everything after that week is an upgrade to one codebase, not a new tutorial.
- **Don't skip fundamentals**: Python and async underpin everything after.
- **Finish each section's "Done When" checklist** before moving on. It is a better signal than the calendar.

## If You Have Less Time

| Situation | Plan |
| --- | --- |
| Already know Python | Skim weeks 1–3, start at week 4 |
| Experienced backend engineer | Skim weeks 1–6, start at week 7. This is the most common case. |
| Just want RAG, nothing else | [Prerequisites](./00-prerequisites/index.mdx), enough [async](./01-python/01-core-python/04-professional-python.mdx#async-python), then weeks 7, 10, 12, 13 |
| No GPU, no interest in serving | Nothing in the grid needs one. Read [NVIDIA NIM](./13-production-genai-and-llmops/01-nvidia-nim-endpoints.mdx) for the hosted-endpoint pattern and skip the rest of the GPU pages. |
| Not building chat | Weeks 7–9, then 16 — [extraction & classification](./08-llm-application-development/03-extraction-and-classification.mdx) is the shape most production work takes — then 21 |
| Interview in a month | Weeks 12–15 and 21, then [17 · AI Interview Roadmaps](./17-interview-roadmaps/index.mdx) |
| Building agents at work already | Weeks 18–20 and 21, then back-fill |

## The Minimum Viable Path

If twenty-two weeks is not realistic, these six weeks get you a defensible
project: **7, 10, 12, 13, 14, 21.** Local model, embeddings, a working RAG
service, retrieval you have tuned, one pattern applied deliberately, and
numbers proving it got better. That is a real portfolio piece.

## Adjusting the Plan

Life happens. If a week slips, shift the rest — the **order** matters more than
the calendar. The one non-negotiable: finish with a working, evaluated project
you can talk about.
