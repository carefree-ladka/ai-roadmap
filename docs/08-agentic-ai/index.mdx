## Chains vs Agents

```mermaid
flowchart LR
    subgraph Chain["Chain (fixed)"]
      A1[Step 1] --> A2[Step 2] --> A3[Step 3]
    end
    subgraph Agent["Agent (decides)"]
      G[Goal] --> Think[Reason]
      Think --> Act[Use a tool]
      Act --> Obs[Observe]
      Obs --> Think
      Think --> Done[Finish]
    end
```

A chain runs the same steps every time. An **agent** loops: it reasons, picks a
tool, observes the result, and repeats until the goal is met.
