print results.

## Why Does It Matter?

Every later topic (functions, classes, async, FastAPI) is built from these
primitives. Getting them fluent removes friction everywhere else.

## Core Concepts

### Variables

Python variables are names bound to objects. No type declaration needed:

```python
name = "Ada"        # str
age = 36            # int
height = 1.7        # float
is_engineer = True  # bool
nothing = None      # NoneType
```

### Primitive Types

| Type | Example | Notes |
| --- | --- | --- |
| `int` | `42` | Arbitrary precision |
| `float` | `3.14` | 64-bit double |
| `str` | `"hi"` | Immutable, Unicode |
| `bool` | `True` | Subclass of `int` |
| `NoneType` | `None` | The "no value" singleton |

### Type Conversion

```python
int("10")      # 10
float("3.14")  # 3.14
str(42)        # "42"
bool("")       # False  (empty string is falsy)
bool("x")      # True
```

### Operators

```python
7 // 2     # 3   floor division
7 % 2      # 1   modulo
2 ** 10    # 1024 exponent
3 == 3.0   # True  value equality
3 is 3     # identity (avoid for numbers/strings)
"a" in "cat"   # True  membership
```

### Strings and f-strings

Strings are immutable. Prefer **f-strings** for formatting:

```python
name = "Ada"
score = 0.9876
print(f"{name} scored {score:.2%}")   # Ada scored 98.76%
print(f"{name=}")                      # name='Ada'  (debug form)

text = "  Hello, World  "
text.strip().lower().replace(",", "")  # 'hello world'
```

### Input / Output

```python
name = input("Your name: ")   # reads a line as str
print("Hello", name, sep=" ", end="\n")
```

### Comments

```python
# single-line comment

def area(r: float) -> float:
    """Return the area of a circle (docstring)."""
    return 3.14159 * r * r
```

## PEP 8 and Pythonic Code

**PEP 8** is Python's style guide. Highlights:

- 4 spaces per indentation level (never tabs mixed with spaces).
- `snake_case` for variables/functions, `PascalCase` for classes, `UPPER_CASE` for constants.
- Max line length ~79–99 chars.
- One import per line; group standard lib / third-party / local.

"Pythonic" means using the language's idioms rather than translating another
language:

```python
# Not Pythonic
result = []
for i in range(len(items)):
    result.append(items[i] * 2)

# Pythonic
result = [x * 2 for x in items]
```

## Common Mistakes

- Using `is` to compare values (`x is 5`). Use `==` for equality; `is` is identity.
- Assuming strings are mutable — `s[0] = "H"` raises `TypeError`.
- Mixing tabs and spaces.
- Building strings with `+` in loops instead of `"".join(...)`.

## Interview Questions

- What's the difference between `==` and `is`?
- Why are strings immutable, and what are the implications?
- What is truthiness? Which values are falsy? (`0`, `""`, `[]`, `{}`, `None`, `False`)

## Things to Remember

- `f"..."` is the default way to format.
- `snake_case` for names; `PascalCase` for classes.
- Everything is an object, including functions.
