## What Is It?

OOP organizes code into **objects** that bundle data (attributes) with
behavior (methods).

## Why Does It Matter?

FastAPI services, Pydantic models, and repositories are all classes. Clean OOP
makes systems easy to extend and test.

## Classes and Objects

```python
class Account:
    currency = "USD"                     # class attribute (shared)

    def __init__(self, owner: str, balance: float = 0.0) -> None:
        self.owner = owner               # instance attribute
        self.balance = balance

    def deposit(self, amount: float) -> None:
        self.balance += amount

acc = Account("Ada", 100.0)
acc.deposit(50)
acc.balance                              # 150.0
```

`__init__` is the constructor; `self` is the instance.

## Method Types

```python
class Temperature:
    def __init__(self, celsius: float):
        self.celsius = celsius

    def to_fahrenheit(self) -> float:        # instance method
        return self.celsius * 9 / 5 + 32

    @classmethod
    def from_fahrenheit(cls, f: float):      # alternative constructor
        return cls((f - 32) * 5 / 9)

    @staticmethod
    def is_freezing(celsius: float) -> bool: # no self/cls
        return celsius <= 0
```

## The Four Pillars

### Encapsulation

Bundle state and expose a controlled interface. A leading underscore signals
"internal":

```python
class Wallet:
    def __init__(self):
        self._balance = 0        # convention: internal

    @property
    def balance(self) -> int:    # read-only access
        return self._balance
```

### Inheritance vs Composition

```python
class Animal:
    def speak(self) -> str:
        return "..."

class Dog(Animal):               # inheritance: "is-a"
    def speak(self) -> str:
        return "Woof"

class Engine:
    def start(self): ...

class Car:                       # composition: "has-a"
    def __init__(self):
        self.engine = Engine()
```

Prefer **composition** when the relationship isn't a true "is-a".

### Polymorphism

```python
def announce(animal: Animal) -> str:
    return animal.speak()        # works for any Animal subclass
```

### Abstraction

Hide implementation behind a stable interface (see ABCs and protocols below).

## Dunder (Magic) Methods

```python
class Money:
    def __init__(self, cents: int):
        self.cents = cents

    def __repr__(self) -> str:
        return f"Money({self.cents})"

    def __eq__(self, other) -> bool:
        return isinstance(other, Money) and self.cents == other.cents

    def __add__(self, other):
        return Money(self.cents + other.cents)

Money(100) + Money(50)           # Money(150)
```

## Dataclasses

For "data holder" classes, `@dataclass` removes boilerplate:

```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    roles: list[str] = field(default_factory=list)
    active: bool = True

User("Ada")                      # User(name='Ada', roles=[], active=True)
```

It auto-generates `__init__`, `__repr__`, and `__eq__`.

## Abstract Base Classes (ABCs)

Define a required interface subclasses must implement:

```python
from abc import ABC, abstractmethod

class Storage(ABC):
    @abstractmethod
    def save(self, key: str, value: bytes) -> None: ...

class MemoryStorage(Storage):
    def __init__(self):
        self._data = {}
    def save(self, key: str, value: bytes) -> None:
        self._data[key] = value
```

## Protocols (Structural Typing)

Protocols describe capabilities without inheritance ("duck typing" with type
checks):

```python
from typing import Protocol

class Readable(Protocol):
    def read(self) -> str: ...

def load(source: Readable) -> str:   # anything with read() fits
    return source.read()
```

## Common Mistakes

- Putting mutable defaults directly on the class (use `field(default_factory=...)`).
- Deep inheritance hierarchies where composition would be simpler.
- Forgetting `__repr__`, making objects hard to debug.

## Things to Remember

- `@dataclass` for data holders; ABC/Protocol for interfaces.
- Prefer composition over inheritance.
- Implement `__repr__` for debuggability.
