## What Is It?

Control flow decides *which* code runs and *how many times*. Functions package
reusable logic behind a name.

## Why Does It Matter?

Clear control flow and well-shaped functions are the difference between code
you can read next month and code you can't. FastAPI route handlers *are*
functions.

## Control Flow

### if / elif / else

```python
def grade(score: int) -> str:
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    else:
        return "C"
```

### Loops: for, while, range

```python
for i in range(3):        # 0, 1, 2
    print(i)

n = 3
while n > 0:
    n -= 1
```

### enumerate and zip

```python
names = ["Ada", "Alan"]
for index, name in enumerate(names, start=1):
    print(index, name)          # 1 Ada / 2 Alan

scores = [95, 88]
for name, score in zip(names, scores):
    print(name, score)          # Ada 95 / Alan 88
```

### break / continue

```python
for x in range(10):
    if x == 5:
        break        # stop the loop
    if x % 2 == 0:
        continue     # skip to next iteration
    print(x)         # 1, 3
```

### match / case (Python 3.10+)

```python
def describe(status: int) -> str:
    match status:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case code if code >= 500:
            return "Server Error"
        case _:
            return "Other"
```

### Comprehensions

```python
squares = [x * x for x in range(5)]              # list
evens = {x for x in range(10) if x % 2 == 0}     # set
lookup = {c: ord(c) for c in "abc"}              # dict
```

## Functions

### Parameters and Arguments

```python
def connect(host: str, port: int = 5432, *, timeout: float = 5.0) -> str:
    return f"{host}:{port} (timeout={timeout})"

connect("db")                       # positional + defaults
connect("db", 6543)                 # override port
connect("db", timeout=2.0)          # keyword-only after *
```

- **Positional**: matched by order.
- **Keyword**: matched by name.
- **Default**: used when the caller omits the argument.
- Everything after `*` is **keyword-only**.

### *args and **kwargs

```python
def log(*args, **kwargs):
    print("positional:", args)     # tuple
    print("keyword:", kwargs)      # dict

log(1, 2, level="INFO")
# positional: (1, 2)
# keyword: {'level': 'INFO'}
```

### lambda and higher-order functions

```python
nums = [3, 1, 2]
sorted(nums, key=lambda n: -n)      # [3, 2, 1]

def apply(fn, value):               # higher-order: takes a function
    return fn(value)

apply(str.upper, "hi")              # "HI"
```

### Scope and LEGB

Name lookup follows **LEGB**: Local → Enclosing → Global → Built-in.

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        return x            # finds 'enclosing'
    return inner()
```

### Closures

A closure is an inner function that remembers variables from its enclosing
scope:

```python
def multiplier(factor):
    def multiply(n):
        return n * factor    # 'factor' is captured
    return multiply

double = multiplier(2)
double(10)                   # 20
```

## Common Mistakes

- **Mutable default arguments**: `def f(items=[])` shares one list across calls. Use `None` and create inside.

```python
def append(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

- Forgetting `range` is exclusive of its end value.
- Overusing `lambda` where a named function reads better.

## Things to Remember

- Keyword-only args (after `*`) make call sites self-documenting.
- Default arguments are evaluated **once**, at definition time.
- Comprehensions beat manual `append` loops for clarity.
