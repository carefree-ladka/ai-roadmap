## What Is It?

- A **module** is a single `.py` file.
- A **package** is a directory of modules (historically marked by `__init__.py`).
- An **environment** is an isolated set of installed dependencies.

## Why Does It Matter?

Real projects span many files and third-party libraries. Getting imports and
environments right prevents "works on my machine" problems.

## Modules and Imports

```python
# math_utils.py
def add(a, b):
    return a + b

PI = 3.14159
```

```python
# main.py
import math_utils
from math_utils import add, PI
from math_utils import add as plus

math_utils.add(1, 2)
add(1, 2)
```

## Packages

```text
app/
├── __init__.py
├── services/
│   ├── __init__.py
│   └── retrieval.py
└── main.py
```

### Absolute vs Relative Imports

```python
# absolute (recommended — clear and robust)
from app.services.retrieval import search

# relative (from within the package)
from .services.retrieval import search
from ..config import settings
```

Prefer **absolute imports** for readability; relative imports are handy inside
a package.

### `__init__.py`

Marks a directory as a package and can expose a curated public API:

```python
# app/services/__init__.py
from .retrieval import search   # enables: from app.services import search
```

## Virtual Environments

Isolate dependencies per project:

```bash
python3 -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
deactivate                    # leave the environment
```

## pip and requirements.txt

```bash
pip install fastapi uvicorn
pip freeze > requirements.txt     # snapshot exact versions
pip install -r requirements.txt   # reproduce elsewhere
```

A `requirements.txt` might look like:

```text
fastapi
uvicorn[standard]
requests
pydantic
```

## pyproject.toml

The modern, standardized project metadata + dependency file. With tools like
Poetry or `uv`:

```toml
[project]
name = "rag-api"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
  "fastapi",
  "uvicorn[standard]",
  "pydantic",
]

[project.optional-dependencies]
ai = ["chromadb", "sentence-transformers"]
```

### requirements.txt vs pyproject.toml

| | requirements.txt | pyproject.toml |
| --- | --- | --- |
| Purpose | Pinned install list | Project metadata + deps |
| Lockfile | No (manual pins) | Yes (via Poetry/uv) |
| Best for | Simple apps, CI installs | Reproducible builds, packaging |

## Common Mistakes

- Installing into system Python instead of an activated `.venv`.
- Circular imports (module A imports B which imports A) — refactor shared code out.
- Committing `.venv/` to Git.

## Things to Remember

- One `.venv` per project; activate it every session.
- Absolute imports for clarity.
- `pip freeze` after installing to keep `requirements.txt` current.
