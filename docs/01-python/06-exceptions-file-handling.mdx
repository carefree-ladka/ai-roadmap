## What Is It?

- **Exceptions** signal that something went wrong.
- **File handling** reads and writes data on disk.

## Why Does It Matter?

Production code fails in predictable ways (missing files, bad input, network
errors). Handling those cleanly is what separates a prototype from a service.

## Exceptions

### try / except / else / finally

```python
def parse_int(text: str) -> int | None:
    try:
        value = int(text)
    except ValueError:
        return None            # handle the expected failure
    else:
        return value           # runs only if no exception
    finally:
        print("attempted parse")   # always runs (cleanup)
```

### Catching specific exceptions

```python
try:
    risky()
except (TimeoutError, ConnectionError) as exc:
    print(f"network issue: {exc}")
except Exception as exc:       # broad catch last
    print(f"unexpected: {exc}")
```

Catch the **most specific** exception you can. Avoid bare `except:`.

### raise

```python
def withdraw(balance: float, amount: float) -> float:
    if amount > balance:
        raise ValueError("insufficient funds")
    return balance - amount
```

### Custom Exceptions and Hierarchy

```python
class AppError(Exception):
    """Base class for this app's errors."""

class NotFoundError(AppError):
    ...

class ValidationError(AppError):
    ...

try:
    raise NotFoundError("user 42 not found")
except AppError as exc:        # catches all app errors
    print(exc)
```

Built-in hierarchy highlights: `BaseException` → `Exception` → `ValueError`,
`TypeError`, `KeyError`, `OSError`, etc.

## Context Managers

`with` guarantees cleanup (closing files, releasing locks) even on error:

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
# file is closed automatically here
```

Build your own with `contextlib`:

```python
from contextlib import contextmanager

@contextmanager
def timer():
    import time
    start = time.perf_counter()
    try:
        yield
    finally:
        print(f"took {time.perf_counter() - start:.3f}s")

with timer():
    do_work()
```

## File Handling

### Reading and writing

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("hello\n")

with open("out.txt", encoding="utf-8") as f:
    for line in f:             # memory-efficient line iteration
        print(line.rstrip())
```

### pathlib (modern paths)

```python
from pathlib import Path

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)
(data_dir / "notes.txt").write_text("hi", encoding="utf-8")
list(data_dir.glob("*.txt"))
```

### JSON

```python
import json

payload = {"name": "Ada", "roles": ["admin"]}
text = json.dumps(payload, indent=2)
back = json.loads(text)

with open("user.json", "w", encoding="utf-8") as f:
    json.dump(payload, f)
```

### CSV

```python
import csv

with open("rows.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerow({"name": "Ada", "score": 95})
```

### Environment Variables

```python
import os

log_level = os.environ.get("LOG_LEVEL", "INFO")   # with default
```

For real apps, load a `.env` file (see [Backend Patterns](./11-python-backend-patterns.mdx)).

## Common Mistakes

- Bare `except:` that swallows everything (including `KeyboardInterrupt`).
- Not using `with`, leaking file handles.
- Hardcoding file paths as strings instead of `pathlib`.
- Forgetting `encoding="utf-8"` (platform-dependent bugs).

- Catch specific exceptions; let unexpected ones surface.
- `with` for anything that needs cleanup.
- `pathlib` over string paths.
