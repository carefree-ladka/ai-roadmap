## Goal

Walk into an AI engineering interview able to explain any layer of the stack:
how the model works, how retrieval works, how you'd evaluate it, how you'd run
it in production, and how you'd keep it safe.

## Estimated Time

Ongoing. Use these as reference, not as a sequence to grind through.

## How to Use This Section

Pick the roadmap matching your next interview, read it top to bottom once, then
revisit the phase headings as a checklist the day before. Each guide assumes
you've already built the corresponding thing earlier in the roadmap — the
reading is much faster that way.

All of it. That's the point of this section.

## Done When

- [ ] You can explain tokens, embeddings, and attention without notes.
- [ ] You can defend your chunking and retrieval choices with numbers.
- [ ] You can describe how you'd evaluate and monitor an LLM feature.
- [ ] You can name three ways an AI system gets attacked and how you'd stop them.
- [ ] You can say when fine-tuning is the wrong answer.
